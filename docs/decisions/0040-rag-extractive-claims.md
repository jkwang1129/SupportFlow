# ADR-0040 RAG 逐句引用原文模式

在需要原文证据的部署中，可以为 RAG 开启逐句核查。单次模型调用只选择资料中的原句，每行一条并附一个来源编号。输出前逐行核对完整句子是否出现在对应检索切片。仍保留原检索、低证据拒答、越界引用和两种编排路径。不需要另加评分模型或索引。

默认关闭 `SUPPORTFLOW_AI_RAG_REQUIRE_EXTRACTIVE_SUPPORT`，待按租户资料类型完成准确率和拒答对照后再考虑启用。逐句核查只证明句子来自指定切片。它不能确认切片的事实和时效，也可能挡住正确转述、依赖标题的句子或复杂多段答案。验证样本同时保留这种代价。回滚关掉配置，恢复现有生成提示和引用编号核查，无数据迁移。
