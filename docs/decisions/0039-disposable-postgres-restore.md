# ADR-0039 在独立 PostgreSQL 集群演练六库恢复

使用 PostgreSQL 自带的逻辑归档，从临时源集群导出六个应用数据库。单独导出角色定义与成员关系，省略密码。以具备不同密码的同名管理员连接空目标，跳过已存在的管理员创建语句，保留角色属性及授予者。随后恢复各个数据库并重新分发临时服务凭据。继续使用原迁移清单和结构契约作核查。演练不连接 Compose 的已有数据卷，也不切换服务地址。

逐库逻辑归档适用于已暂停业务写入的恢复演练。连续写入期间，六次导出无法提供同一个跨库时间点。生产恢复策略需要另外覆盖协调停写、物理备份或 WAL、加密与保留、对象存储及恢复目标。数据库归档使用临时测试数据，只有计数和校验结果留作验收证据。

PG17 恢复会把部分索引与 CHECK 表达式中字符串数组的 `text[]` 转换拆到每一个元素。恢复校验根据已审核契约生成另一种等价文本，严格保留每个字面量、顺序、比较条件、索引字段和有效性。仍拒绝改变任意成员值。角色、权限、RLS、列定义和其他表达式继续原样校验。

演练目标排除已有应用数据库。恢复中断时丢弃临时目标并从原归档重新启动。演练完成后停止并移除两个独立测试实例。没有架构或应用迁移需要回滚。
