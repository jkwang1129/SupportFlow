# ADR-0037 Runtime 已观测模型用量

模型调用预留与每次成功的输出检查点已经持久化。运营核查复用这两份记录，按租户读取单个 Run。取样时短暂锁住 Run，同时读取至多 100 个 MODEL 步骤及尚未过期的检查点。在释放锁后校验摘要、步骤和输出的绑定，再提取 Chat 与 Embedding 的用量。重新读取检查点不会新增调用，所以按步骤统计可避免重复记账。

输出区分已观测的输入 Token、Chat 输出 Token、预留次数和缺失观测的预留次数。模型故障、在途请求、未返回用量，以及检查点到期均可能造成缺失。缺少样本时对应合计为 `null`，供应商明确返回 0 时合计为 0。结果不含提示词、输出、向量、单价或凭据。该输出提供短期逐任务核查。租户日月配额或账单对账需要独立的持久化计量与费用规则。

曾考虑在 Worker 再写一套用量表。当前短期核查可以从原子检查点取得，额外账本会引入重试去重、保留策略和迁移负担。本批保留现有 Runtime 与旧 Workflow 的模型调用入口。回滚时停止调用运营命令即可。无数据库改动。
