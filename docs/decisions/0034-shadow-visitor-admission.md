# ADR-0034 访客文本的只读任务登记

客服服务复用消息落库事件，在已认证服务调用或既有渠道认证后的消息事务中，从后端保存的消息主键登记任务。启用需指定一个客服投递租户并打开 `SUPPORTFLOW_BOT_RUNTIME_SHADOW_ADMISSION_ENABLED`。租户必须与当前事务作用域一致。仅受限租户中、未被接管的进行中会话，其双方可见且有界的访客文本可以登记。

Outbox 在消息事务内落库，业务回滚不会留下可调度的事件。相同客户端消息号复用原消息和事件。选定租户用既有投递器向 AI 发送引用，网络调用与消息事务分离。登记使用数据库保存点。队列满或锁超时时保留已落库的客服消息，并记录稳定错误信息。可选分析任务允许因失败跳过，已成功提交的 Outbox 继续按持久化规则调度。

影子任务用于生成内部报告，既有客服接待和通知继续按原路径运行。开关默认关闭。可先停止登记再处理已登记事件，也可另行停止投递与只读 Worker。回滚保留业务消息、原 Outbox、运行预算及报告。
