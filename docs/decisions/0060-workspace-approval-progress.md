# ADR-0060 坐席工作台的工单执行进度

活动提案接口只列可审批的任务。任务执行完后，工作台会用该坐席在当前会话中见过的批准引用重新请求现有进度接口，读取状态、执行轮数和步骤数。活动提案仍优先展示。若已批准的提案在列表返回后结束，预览返回 404 时同样重新请求进度。每次请求沿用客服服务的坐席权限、租户和来源核验。

关闭弹窗时清除提案正文、进度及在途查询，组件内保留当前会话的最近批准引用。查询到终态后，弹窗只展示已核验状态，撤回入口随提案移除。进度返回 403 或 404 时清除引用及展示内容。临时网络故障可手动重查，重查只调用读取接口。切换会话或坐席身份会重新挂载组件。工作台用选择序号丢弃已退出会话的迟到详情和消息响应。

## 复现与回退

从 `frontend` 目录使用仓库锁定的依赖运行。

```powershell
npm ci
npx playwright install --only-shell chromium
npm run test:browser
npm run build
```

测试运行真实工作台页面和浏览器，通过预设 HTTP 响应控制请求完成顺序、角色、断线和状态变化。审批绑定与持久化结果由 [D16 服务验收](../reliability-verification.md#d16-访客查询与审批建单闭环2026-11-23) 核查。D17 的恢复限于同一页面内的同一坐席和会话。整页重载、实时事件续传和访客端结果展示单独验收。可回退本批提交恢复原界面和测试范围。无数据库迁移。[浏览器验收](../reliability-verification.md#d17-坐席审批与执行进度浏览器回归2026-11-23)
