# ADR-0035 工单规划上下文的结构化历史

工单读取 Loop 在下一轮上下文中保存经过 Schema 与工具执行校验的规划决定。默认仍使用原规划文本。对照模式只将已执行工具决定重新序列化为确定性 JSON，保留工具名、版本和原参数。系统指令、当前客户输入、证据引用及已核验的工具事实均保留。

开启 `SUPPORTFLOW_AI_RUNTIME_CANONICAL_PLANNER_HISTORY=true` 后，独立只读 Worker 使用该策略。策略参与既有 Loop 绑定和后续模型请求摘要。恢复按相同策略重建上下文并保留历史预算。切换策略后，已有不同绑定的任务退出，不继续调用模型。原始模型输出仍在既有受限检查点中，保留当前诊断与恢复能力。

当前对照考察结构化规划中的格式开销。长会话选择、摘要和 Token 节省需分别用实际语料与相应供应商测试。回滚前停下新策略 Worker，处理待恢复任务，再以原配置启动。
