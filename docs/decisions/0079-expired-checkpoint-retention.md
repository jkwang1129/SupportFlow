# ADR-0079 过期 Agent 检查点清理

沿用 `agent_payload.expires_at`。AI 016 增加单租户清理函数，每次最多处理 500 条。仅选已到期正文，且关联任务已经结束并具有有效结束时间。`SIDE_EFFECT_UNKNOWN` 继续保留。覆盖已成功、已失败和已取消的任务，运行和审批等待的数据保持可供既有流程处理。

默认预览用只读事务统计一批候选。实际清理重新检查条件，按到期时间和主键排序，锁定任务与正文并跳过已锁定行。进程提交后才输出结果。并发或行锁可能导致预览和实际计数不同，后续批次可补处理跳过项。只删除正文行，任务、步骤、用量回执、审批和核销记录保留各自原有证据。旧版过期正文缺少用量回执时，仍沿用已有的未知用量语义。

使用独立 `supportflow_payload_maintenance` 能力组。AI 016 默认没有为该组创建登录账号，也没有向 Runtime 组授权执行。数据库管理员可按组织授权给专用运维登录 `CONNECT`、`USAGE` 和该能力组。应用和租户业务账号继续使用原权限。维护连接仅调用固定函数，返回批次计数和租户，无需读取正文。现场运维记录保留各批的预览和执行计数。

复现 `python scripts/test-agent-runtime.py`。数据库迁移走权威清单，AI 015 到 016 保留所有已有正文和账本。回退时停用调度或收回维护登录的组成员资格，已有数据库迁移历史保留。已提交删除的正文只能从仍然保留且符合保留策略的备份中恢复。备份副本与其他业务数据的到期策略单独验收。
