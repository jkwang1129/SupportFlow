# ADR-0072 旧知识库向量化使用共用模型传输

内置与 LlamaIndex 两种知识库引擎都调用共用向量化入口。LlamaIndex 继续负责读取与切块。知识库索引、检索和训练语料向量化继续使用已有的供应商、模型、专用密钥或千问密钥配置。显式设置本地向量时，两种引擎都直接使用本地哈希。

保留每批最多 10 条、1024 维和每次向量化复用连接的行为。每个远程批次使用同一连接、响应头和正文截止时间，按共用传输检查 HTTP 状态、MIME、JSON 和请求及响应的 256 KiB 上限。每批提交一次。响应按索引复原顺序，要求输入与条数一一对应，拒绝重复或缺失索引、非数值、非有限值和绝对值大于 100 万的分量。

任一批失败时，整次调用以本地哈希计算全部输入。索引继续保存这一向量来源，检索继续走原关键词降级。新远程结果以 `供应商:模型` 标记，已有切片与历史来源字段按原值读取。失败日志只记录调用链和稳定错误类别。此前已完成的远程批次仍可能产生供应商费用。

同步的模型与数据库工作在知识库异步接口、线性 RAG 和对话训练匹配入口通过工作线程执行。LangGraph 的同步检索节点继续由其异步执行器调度。切片替换和删除对同一租户和文档使用事务锁，从删旧到写新保持原子提交。锁只在写数据库时取得，远程向量计算仍独立进行。

## 验收与回退

- 在 `ai-service` 执行 `python -m pytest -q tests/test_legacy_embedding_transport.py tests/test_chat_transport.py tests/test_runtime_embeddings.py`。以签名知识库接口及本机供应商验证协议，并验证两种检索引擎、批次失败和训练版本匹配。
- 在仓库根执行 `python scripts/test-customer-rls.py --with-ai`。两个同文档争用用例使用受限数据库账号，验证重叠替换与删除的等待和提交顺序，以及其他文档可独立写入。
- 紧急降级可将 `SUPPORTFLOW_AI_EMBEDDING_PROVIDER` 设为 `local` 并重启 AI 服务。通常回退到上一版 AI 镜像即可恢复旧调用方式。替换与删除的锁可独立保留。现有切片保留，应用无需数据库迁移。

本批的截止时间按远程批次计算。请求方断开时，已经在工作线程中运行的旧索引仍按原流程完成。真实供应商兼容性、检索质量、多实例容量和供应商账单需在目标环境单独验收。
