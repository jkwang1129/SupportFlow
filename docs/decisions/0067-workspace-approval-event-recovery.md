# ADR-0067 坐席工作台自动补拉任务事件

审批窗口显示当前任务的时间线。活动提案直接提供事件和任务引用。整页重载时，工作台通过 `latest-progress?includeTimeline=true` 重新定位任务。服务端先核验坐席、租户、会话及快照，再额外返回事件和任务两个引用。默认进度接口仍返回三个原字段，每次分页继续执行来源与角色核验。

窗口内按任务和事件序号保存游标，每次最多读取 16 条。浏览器只在页面校验通过后推进游标，接受连续的新事件并过滤重叠序号。历史页读完后，每 2 秒检查一次新事件，同一时间最多一个读取请求，单次请求超时为 8 秒。读到终态后停止补拉。界面保留最近 32 条事件。

离线时暂停计时并取消正在读取的请求，恢复后从已确认的游标继续。超时或服务暂时不可用时，重试间隔从 2 秒递增至最多 16 秒。查询发现来源或权限失效时清空当前任务视图。已记录的终态事件直接更新状态并撤下审批操作，执行次数和步骤计数仍通过进度接口获取。游标越界或响应存在缺口时停止自动查询，坐席可以手动刷新。关闭窗口、切换会话或坐席变更时销毁该订阅及内存游标。重新打开或整页重载按当前任务从头读取。

## 复现与回退

- 在 `frontend` 运行 `npm run test:browser` 和 `npm run build`。浏览器通过受控 HTTP 夹具验证断网、重叠页、慢请求取消、来源过期、临时失败和跨页恢复。
- 在仓库根目录运行 `mvn -B -f backend/pom.xml verify`、`python scripts/test-customer-rls.py --with-ai` 和 `python scripts/test-agent-runtime.py --with-java-delivery`。联调重新定位任务后读取实际服务事件，并检查普通坐席与其他租户拒绝。
- 在完成 D23 部署后依次升级客服服务和前端。应用回退按前端、客服服务顺序恢复，保留 D23 任务事件及迁移历史。
