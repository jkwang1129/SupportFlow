# ADR-0041 通过已有审批权限读取任务进度

坐席的任务进度查询复用客服服务的管理员或主管审批权限。通过事件和 Run 引用核对原会话来源后，客服服务用已有服务签名请求 AI Runtime 状态。收到状态后复核租户、事件和 Run，再查一次当前会话权限。界面可获得状态、执行轮数和步骤数。原始错误、正文、工具参数和结果引用保留在内部。

这一批先交付可重读的 HTTP 状态。可独立验证断线之后的查询语义，无需增加事件表或订阅并发。页面、异步推送和用户取消单独交付。禁用既有审批服务配置可撤下查询。无数据库迁移。

读接口为 `GET /api/customer/agent-approvals/events/{eventId}/runs/{runId}/progress`。用当前登录坐席的身份核权，返回 `state`、`attempt` 和 `step_count`。Run 状态反映当前执行进度；工单写入仍以业务回执为准。源快照过期或会话被接管时，原授权规则会停止返回进度。
