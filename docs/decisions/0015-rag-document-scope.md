# ADR-0015：检索降级保留文档范围

日期：2026-11-21。知识工具接入前核实到：原向量SQL支持doc_ids，但内置/LlamaIndex关键词兜底都未传递该范围；API和图又把[]归并成None。检索策略或空选集因此可能扩大文档选择。已有租户RLS与软删除条件保持；这是文档选择不一致，不能将所有检索条件直接称为现有完整文档ACL。

采用一个小的document_scope校验函数，None表示保留当前调用方的租户检索范围，[]表示不选择任何文档；非空列表最多200个正int64，拒绝bool/字符串/负数/超限，按首次出现去重。不是授权函数：指定doc_id不会授予租户/文档权限；发布状态、客户资源授权及索引版本仍需后续知识工具边界。

范围贯穿问答/独立检索API→LangGraph/linear→retriever→内置/LlamaIndex→向量与关键词SQL。四条关键词兜底路径显式传递原doc_ids；SQL仍通过参数化ANY、同租户JOIN/RLS和is_deleted过滤。空范围在图/检索入口/存储层短路，无Embedding、数据库查询或回答生成，图不做无用改写，以empty_document_scope拒答。两条图路径共用分支函数，防止只修LangGraph漏掉线性实现。LlamaIndex全零向量也与内置策略一致走有范围的关键词兜底，不用无意义余弦结果假装有效召回。

兼容边界：省略docIds或传null仍按原租户范围查询；现有Java KbAiClient.ask不发送docIds，默认链路保持。明确[]现在选空而非选全部，这是有意收紧；需要全租户检索的可信调用方应省略字段。ID输入现在严格是JSON正整数，不再将bool/数字字符串悄悄转换成文档选择。此规则不替代请求服务认证/可信租户/RLS。

自动化验证覆盖48项范围单元/图/API/负面测试（首批39项修复前33失败、6通过；追加KB独立检索入口9项修复前7失败、2通过），两引擎关键词回退、None/[]差异、空范围零I/O、非法参数在I/O前拒绝；7项真实KB受限角色PG用例覆盖向量/关键词、跨租户/已删除/范围外文档、两引擎本地/零向量/向量无命中后兜底。模型/向量为合成数据，无付费语义质量或性能结论；原事实引用缺口仍保留。

无新SQL/Java/依赖/服务/缓存。回滚保留现有数据与Runtime历史；先停用受限文档知识工具接入，不得在存在非空文档限制的调用中回退到会扩大范围的旧兜底。不得通过把[]改成None或吞掉筛选错误来“恢复可用”。完整知识工具、发布/撤权/版本、Embedding预算和日志脱敏另按计划交付。
