# ADR-0043 为客服意图分析设置上下文预算

现有客服大脑由 Java 发送同一会话的消息，AI 从现有会话状态读取槽位。首批为意图分析增加可选的 UTF-8 消息预算。保留完整系统指令和当前问题，将最近的对话和已有槽位以结构化数据发送。已恢复槽位仅投影模型合同使用且符合格式的订单号与手机号。按最近优先选择完整消息，直到达到预算。系统指令、当前问题和槽位本身超限时，沿用现有规则兜底。

使用 `SUPPORTFLOW_AI_BRAIN_CONTEXT_MAX_BYTES` 启用。默认 `0` 使用现行方式。本批不新增历史查询、摘要调用、数据写入或数据保留期。模型输入字节可确定性复现，实际 Token 和语义质量需要在固定模型与授权语料上另测。回滚设为 `0`，原对话和槽位继续由既有代码保存。
